# Security Policy

This is a portfolio/research project; there is no formal support or SLA.

## Reporting a Vulnerability

If you find a vulnerability, please report it privately via GitHub's
"Report a vulnerability" (Security tab -> Advisories) rather than a public
issue. You can expect an acknowledgement within a few days.

Do not include real credentials, API keys, or cloud account details in any
report, issue, or pull request.
